# BitVa Laravel Starter

Laravel 12
PHP 8.3
Tailwind CSS 4
Alpine.js
MySQL

## Features

- Authentication
- Responsive admin dashboard
- Reusable Blade components
- User management
- Roles and permissions
- Settings
- Activity logs
- File management
- Excel exports
- Dynamic form engine
